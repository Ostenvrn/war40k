## 📖 О проекте

**War40k** — это текстовая RPG, где игрок начинает с самых низов
и проживает жизнь от безымянного отброса до легенды (или падения в Хаос).

Ключевая идея: **судьба ведёт игрока**, а не он выбирает свой путь из меню.
Каждое решение, каждый контакт с Варпом, каждая проявленная жестокость
или милосердие — всё это формирует то, кем он станет.

---

## 🎯 Особенности

- 🎭 **27 уникальных путей** — ордена Астартес, легионы Хаоса, Инквизиция, Механикус и др.
- 🗺️ **Карта с перемещением** — гибридная карта, день/ночь, скрытая шкала событий.
- 🧬 **100+ пассивных меток** — предметы, воспоминания, шрамы, влияющие на персонажа.
- 📓 **Дневник персонажа** — записи, которые отражают его мысли и страхи.
- ⚠️ **Скрытая порча** — игрок не видит шкалу, только последствия.
- 💀 **Окончательная смерть** — но с сохранениями.

## 🚀 Установка и запуск

### Требования

- Python 3.10+
- Flet 1.0+

### Установка

```bash
# Клонируйте репозиторий
git clone https://github.com/Ostenvrn/war40k.git
cd war40k

# Создайте виртуальное окружение
python3 -m venv .venv
source .venv/bin/activate

# Установите зависимости
pip install --upgrade pip
pip install 'flet[all]'
